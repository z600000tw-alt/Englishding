從影片字幕找出值得學的單字

貼上影片連結和字幕（或上傳 .srt / .vtt 字幕檔），AI 會依你的程度挑出單字、片語，標出重要度與實用度，並自動補齊意思、例句、同反義字等。每張卡片都會連回影片中出現的那一秒。

怎麼取得 YouTube 字幕？
  1. 在電腦版 YouTube 影片下方點「…更多」→「顯示轉錄稿」。
  2. 右側出現轉錄稿後，從第一行拖曳選取到最後一行，複製後貼到上面（含時間戳記最好，卡片就能跳到影片對應秒數）。
  3. 也可以用字幕下載網站取得 .srt 檔再上傳。
  4. 網頁本身無法直接讀取影片內容，所以需要字幕文字。

我的學習

使用說明

1. 快速開始

  1. 到「單字」→「＋ 新增單字」，勾選多益基礎單字包的主題後按「載入」。
  2. 回到「今日」，按「開始複習」，把今天的份完成即可。複習時點卡片翻面，右滑代表記得、左滑代表忘記，也可以按下方四個評分按鈕。
  3. 每天新卡數量可在「我的 → 設定與備份」調整（預設 15 個）。

2. 複習時怎麼評分

  • 忘記：想不起來或答錯，幾分鐘後會再出現。
  • 困難：想很久才想到，間隔會拉得比較短。
  • 良好：正常想起來，最常用的按鈕。
  • 簡單：完全不用想，間隔會拉很長。

不確定時請誠實按「忘記」，系統才能幫你安排正確的複習時間。重要度、實用度高的字會更常出現；難度高的字一開始間隔較短。

鍵盤快捷鍵：空白鍵翻面／良好、1–4評分、S標記、R發音、U復原。

3. 複習會輪流出現的題型

  • 看字想意思、看中文拼英文、例句克漏字。
  • 已經熟悉的字會出現「用單字造句」，寫完由 AI 批改並給修正建議。
  • 可在設定中開關各種題型。

4. 從影片學單字

  1. 到「影片」貼上影片連結與字幕（YouTube 可點影片下方「…更多 → 顯示轉錄稿」後複製），或上傳 .srt / .vtt 字幕檔。
  2. 選擇你的程度後按「分析字幕找單字」，勾選想學的字加入。
  3. 每張卡片都會附上影片原句，並可從該秒數開始播放。

4-0. 發音

點一下英文就會唸出來：單字、例句（點中文翻譯或句子空白處唸整句）、同義字、反義字、詞性變化、常用搭配都可以點。

4-1. 例句中的生字

看例句時遇到不熟的字，直接點那個字（或用滑鼠選取一段片語），按「加入單字」就會加入單字庫，並自動加上 #例句生字 標籤、保留原本的例句。設定 Gemini 金鑰時可以不填中文，AI 會依照例句的意思補上。

5. 標記與標籤

複習時點右上角「⋯」，或在單字庫查看單字時，可以「☆ 標記」或加上「# 標籤」（例如 #易混淆、#發音難）。在「今日」頁的「範圍」選單、單字庫、活用練習中，都可以只挑選已標記或某個標籤的字。

6. 活用練習

「練習」頁可用學過的字產生情境短文填空、對話填空、近義字辨析選擇題、中翻英造句。答錯的字會自動排入今天的複習。

7. 和朋友一起學（班級）

  1. 把網址傳給朋友：朋友打開網站後，選「匿名開始」或「用 Google 帳號登入」，再設定暱稱與頭像。
  2. 建立班級：到「班級」輸入班級名稱按「建立」，把畫面上的邀請碼傳給朋友。
  3. 朋友加入：朋友在「班級」輸入邀請碼按「加入」。
  4. 共享單字：在「學習集」選擇你的牌組按「分享／更新」。朋友按「加入學習」後，單字會複製到他自己的單字庫；你之後新增單字再按一次「分享／更新」，朋友下次開啟時會自動收到新字。

學習進度互不影響：每個人的單字、複習進度、評分紀錄、標記、筆記都存在自己帳號的私人空間，資料庫規則限定只有本人能讀寫，其他人（包括班級建立者）都看不到也改不到。班級裡共享的只有「學習集的單字內容」、你的暱稱與頭像，以及排行榜上的統計數字（本週 XP、今日複習數、連續天數、已學字數）；不想公開數字可在班級頁取消勾選「在排行榜顯示我的進度」。

8. 對戰遊戲與紀錄

  • 連連看：配對英文與中文，配錯加罰 1 秒，最快完成者獲勝。
  • 快問快答：每題 10 秒，含聽音選意思，答得越快分數越高。
  • 房主建立遊戲後把遊戲碼傳給朋友，大家進房後由房主按「開始」，所有人同時倒數開賽，即時看到彼此進度。沒趕上的人之後也能挑戰同一組題目。
  • 「對戰紀錄」會保存每場比賽的名次與成績，並統計你和每位同學的勝負與勝率、你的最佳成績。
  • 遊戲中答錯的字只會排入你自己的複習，不影響別人。

9. 加到手機主畫面

  • iPhone／iPad：用 Safari 開啟本網站 → 點下方「分享」按鈕 → 「加入主畫面」→「新增」。
  • Android：用 Chrome 開啟 → 右上角「⋮」→「加到主畫面」或「安裝應用程式」。
  • 之後點主畫面上的「Vocab Studio」圖示就會全螢幕開啟，資料和網頁版完全相同。

9-1. 備份

建議每月到「設定與備份」按「產生備份」並複製保存一份，需要時可貼回還原。

10. 帳號與登入

  • 匿名開始：免註冊，資料綁定在目前這個瀏覽器。清除瀏覽資料、換手機或登出後就無法找回。
  • 綁定 Google：在「我的 → 帳號」按「綁定 Google 帳號」，目前的資料會完整保留，之後在任何裝置用同一個 Google 帳號登入即可。
  • 右上角的頭像可以快速進入帳號頁，更換暱稱與頭像。

11. 管理員

  • 班級管理員：建立班級的人就是班級管理員，可在班級的「管理」分頁更改班級名稱、移出成員、刪除學習集與遊戲、刪除班級，並可把其他成員設為管理員協助管理。
  • 網站管理員：網站架設者可以在 Firebase 把自己設為網站管理員（步驟見 README），之後「我的」頁會出現「網站管理」，可查看並管理所有班級。
  • 任何管理員都看不到其他人的個人單字與複習進度。

12. 關於 AI 功能

字幕找單字、自動補齊單字細節、造句批改、AI 出題等功能使用 Google Gemini。請到「我的 → 設定與備份」依步驟申請免費的 API 金鑰並貼上（金鑰只存在你的瀏覽器）。沒有金鑰時，複習、多益單字包、班級與對戰遊戲都能正常使用。大量匯入單字時建議選「學到該字時才補齊」，避免一次用掉免費額度。

發音

  1. 到 Azure 入口網站 註冊並登入。
  2. 上方搜尋「語音服務」（Speech services）→ 建立；定價層選 Free F0，區域選 East Asia 或 Southeast Asia。
  3. 建立完成後進入該資源 →「金鑰與端點」，複製「金鑰 1」和「位置/區域」。
  4. 貼到下面，按「試聽」確認有聲音，再按「儲存設定」。

金鑰只存在這個瀏覽器。每句只產生一次並存在裝置上，重複播放不扣額度；額度用完或出錯會自動改用裝置語音。中文會用台灣華語女聲。

想要更自然：iPhone 到「設定 → 輔助使用 → 朗讀內容 → 聲音 → 英文」下載標示「加強版」或「高品質」的聲音；電腦建議用 Chrome 或 Edge（Edge 有 Natural 語音）。

第一次唸某個字會花 1～2 秒產生，之後會存在這台裝置上，再唸就是即時的。使用你的 Gemini 免費額度；額度用完時會自動改用裝置語音。

AI 功能設定（Google Gemini）

字幕找單字、自動補齊例句與同反義字、造句批改、AI 出題都需要 Gemini API 金鑰（Google 提供免費額度）。金鑰只存在這個瀏覽器，不會上傳到資料庫；每位同學請使用自己的金鑰。

  1. 打開 Google AI Studio 的 API 金鑰頁面，用 Google 帳號登入。
  2. 按「Create API key」建立金鑰，按複製。
  3. 貼到下面，按「儲存並測試」。

備份與還原

備份包含所有單字與複習進度。按「產生備份」後複製文字存起來；還原時貼回下方再按「還原」。

其他

複習機制：新卡學習步驟 1 分 → 10 分（難度 4–5 的字多一步 1 小時），畢業間隔 1 天；之後依 SM-2 難易係數拉長間隔，忘記時降 20% 並進入 10 分鐘重學，凌晨 4 點換日。開啟加權時，重要度與實用度 5 顆星的字複習間隔約為一般字的一半，1 顆星的字約 1.5 倍；難度高的字起始難易係數較低。
